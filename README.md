# XMW++
XMW++是一个专门为XMW打造的一个多功能工具箱

为小码王社区 (world.xiaomawang.com) 提供增强功能的用户脚本。

目前版本2.2


---

## ✨ 功能

功能	

全局字体篡改  解决原网页字体难看的问题，可以自定义字体

自定义壁纸	  支持图片 URL或API 或纯色值

用户信息显示	在用户名旁和左下角卡片显示用户ID及注册时间（估算）

深色模式	    全局深色主题切换

自动签到	    每天自动执行签到

RGB模式	    让网页文字持续变色

网页缩放      实际上大部分浏览器都有这个功能，主要照顾移动端用户

自动识别链接   快捷跳转链接

---

## 📦 安装

1. 安装Tampermonkey(油猴)浏览器扩展
2. 导入发布的XMW++.js文件到油猴中 或者[**一键安装 XMW++**](https://raw.githubusercontent.com/Toushou-114514/XMWPP/main/XMW++.user.js)
3. 启用XMW++并刷新小码王社区页面


---

## ⚙️ 使用

现在打开xmw会有一个悬浮球 单击即可打开菜单

(移动端设备可能需要多点几下开可以打开菜单)

新版本抛弃导航栏上的 `[XMW++]` 按钮
