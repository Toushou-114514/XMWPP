# XMW++
XMW++是一个专门为XMW打造的一个多功能工具箱

为小码王社区 (world.xiaomawang.com) 提供增强功能的用户脚本。

目前版本1.0.1

---

## ✨ 功能

| 功能 | 说明 |

| 👤 用户ID显示 | 在用户名旁和左下角卡片显示用户ID |

| 🌙 深色模式 | 一键切换深色/浅色主题 |

| 📅 自动签到 | 每天自动执行签到，每日仅触发一次 | 可能有bug

| 🖐️ 手动签到 | 一键签到，带状态反馈 |

| 🌈 RGB模式 | 页面所有文字变为动态彩色 |

| 🧊 液态玻璃 | 为大部分卡片增加毛玻璃效果 | ~~卡死了~~

| 🖼️ 自定义壁纸 | 个人主页壁纸替换（上传图片 / 输入URL） | 

| 🔲 半透明卡片 | 个人主页卡片半透明化（可调透明度 10%~100%） | 有bug别用

---

## 📦 安装

1. 安装Tampermonkey(油猴)浏览器扩展
2. 导入发布的XMW++.js文件到油猴中
3. 启用XMW++并刷新小码王社区页面

---

## ⚙️ 使用

点击导航栏上的 `[XMW++]` 按钮，打开工具箱弹窗，自由开关各项功能。

所有设置会自动保存在浏览器中，刷新后不会丢失。
