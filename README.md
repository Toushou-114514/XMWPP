# XMW++
## XMW++是一个专门为XMW打造的一个多功能工具箱

**为小码王社区 `world.xiaomawang.com` 提供增强功能的用户脚本。**

目前版本2.3
---
> 一个悬浮球，装下深色模式、自定义壁纸、字体、签到、任务奖励、链接识别……全部功能。
> 所有数据都保存在本地（`localStorage`），不上传、不联网。

---

## ✨ 功能

### 界面 UI

| 功能 | 说明 |
| --- | --- |
| **深色模式** | 全局深色主题。|
| **RGB 模式** | 让网页文字持续流动变色。 |
| **自定义网页壁纸** | 支持**本地图片上传**、**图片 URL**、**纯色值**（如 `#1a1a2e`）。作用于本站**所有页面**，站点自带背景会被自动接管，卡片与文字仍正常显示。 |
| **用户信息显示** | 在用户名旁 / 左下角卡片显示用户 **ID** 及**注册时间（估算）**。 |
| **全局字体** | 自定义网页字体，解决原站字体难看的问题。 |
| **网页缩放** | 30% – 200% 缩放，兼顾移动端。 |

### 功能设置

| 功能 | 说明 |
| --- | --- |
| **自动签到** | 检测到签到按钮就自动点击（另附「手动签到」）。 |
| **自动领取奖励** | 自动点击任务中心中可领取的奖励（另附「手动领取」）。 |
| **自动识别链接** | 识别页面文本中的网址并显示为蓝色，点击即可在新标签页打开。 |
| **404 自动刷新** | 检测到真正的 404 页面时自动刷新一次。默认**关闭**（跳转时可能瞬时出现 404 块，开启后存在误刷新风险）。 |


## 📦 安装

1. 安装Tampermonkey(油猴)浏览器扩展，并启用*允许用户脚本*
2. 导入上面文件发布的XMW++.js文件到油猴中 或者[**点我一键安装 XMW++**](https://raw.githubusercontent.com/Toushou-114514/XMWPP/toushou/XMW++.user.js)
3. 启用XMW++并刷新[**小码王社区**](https://world.xiaomawang.com/)页面

## ⚙️ 使用

现在打开xmw会有一个悬浮球 单击即可打开菜单

*(移动端设备可能需要多点几下开可以打开菜单)*

新版本抛弃导航栏上的 `[XMW++]` 按钮

## 更新日志

### v2.3.2

- **重写深色模式**：改用运行时真实计算样式判断，浅色卡片、文字、边框、链接自动适配，顶部导航栏一并变暗。
- **修复深色模式跳转失效**：切换到新页面后卡片不再漏掉改色；被 React 重渲染覆盖的标记会自动补一次，且不再闪烁。
- **修复「每次跳转都 404」**：根因是脚本删除 React 管理的节点破坏了协调。现已改为注入 CSS 隐藏，视觉一致且不再破坏页面。
- **404 自动刷新改为默认关闭**：可在「功能设置」中手动开启。
