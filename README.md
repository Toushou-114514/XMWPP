# XMW++
XMW++是一个专门为XMW打造的一个多功能工具箱

为小码王社区 (world.xiaomawang.com) 提供增强功能的用户脚本。

目前版本2.0

这个版本重置了所有内容

---

## ✨ 功能

🚀 新增 

功能	说明

全局字体篡改 解决原网页字体难看的问题，可以自定义字体

自定义壁纸	  支持图片 URL 或纯色值（如 #1a1a2e）

用户信息显示	在用户名旁和左下角卡片显示用户ID及注册时间（估算）

深色模式	    全局深色主题切换

自动签到	    每天自动执行签到，支持手动签到

RGB模式	    页面文字动态彩色流动

---

## 📦 安装

1. 安装Tampermonkey(油猴)浏览器扩展
2. 导入发布的XMW++.js文件到油猴中
3. 启用XMW++并刷新小码王社区页面


---

## ⚙️ 使用

点击导航栏上的 `[XMW++]` 按钮，打开工具箱弹窗，自由开关各项功能。

所有设置会自动保存在浏览器中，刷新后不会丢失。
